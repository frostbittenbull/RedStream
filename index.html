Мощные возможности

Один компактный экран — и ничего лишнего

Умные форматы

MKV и MP4 для видео, OPUS, M4A и MP3 для аудио. Разрешения, кодеки и FPS берутся из реальных форматов конкретного ролика, а итоговый размер файла показывается ещё до загрузки.

Предпросмотр на лету

Вставьте ссылку — программа подгрузит миниатюру, название, длительность и лучшее доступное качество. Если не хватает https://, он добавится сам.

Умный подбор формата

Нет AV1 или 60 к/с в выбранном разрешении? RedStream берёт ближайший вариант в том же разрешении, показывает его настоящий размер и предупреждает о замене. Никаких неожиданных загрузок «самого большого видео».

Аудиодорожка и субтитры

У видео несколько языков озвучки? Выберите нужный. Есть субтитры — вшейте их прямо в MKV или MP4. Если выбирать не из чего, кнопки неактивны.

Видео 18+ и cookies

Возьмите cookies из браузера или укажите файл cookies.txt. Во втором случае браузер закрывать не нужно, а файл используется и для предпросмотра.

Перетаскивание ссылки

Перетащите ссылку из браузера, из адресной строки, выделенный текст или файл .url прямо в окно. Старая ссылка заменится новой.

Автоустановка компонентов

Нет рядом yt-dlp.exe, ffmpeg.exe или 7za.exe? При запуске программа скачает недостающее сама. ffmpeg качается в 8 потоков, поэтому быстро.

Самообновление

Вышла новая версия? Нажмите на плашку — RedStream скачает свежий RedStream.exe, заменит им текущий и перезапустится. Отдельные плашки следят за yt-dlp и ffmpeg.

Прокси с авторизацией

HTTP, SOCKS4, SOCKS5 — с логином и паролем или без. Включается в меню «Дополнительно» и передаётся в yt-dlp через --proxy.

Интерфейс без лишнего

Всё управление в одном окне: три меню, плашки с параметрами, живой прогресс. Тёмная тема, собственный заголовок, никаких лишних диалогов.

  • Меню: Настройки · Дополнительно · Помощь
  • Прогресс: поток, %, МБ, скорость и оставшееся время
  • Прогресс дублируется в заголовке окна Windows
  • Сворачивание в системный трей прямо из тулбара
  • Ctrl+C/V/X/Z/A работают в любой раскладке, есть контекстное меню
  • F1 — справка, Esc — закрыть всплывающее окно
  • Плашки с параметрами недоступны, пока выбирать не из чего
  • Сплэш-экран с плавным появлением при запуске

Форматы и кодеки

Максимальная гибкость — под каждое видео отдельно

Видео контейнеры

MKV MP4

Слияние видео и аудио потоков — через FFmpeg. Субтитры вшиваются прямо в контейнер.

Аудио форматы

MP3 M4A OPUS

MP3 скачивается с максимальным качеством (--audio-quality 0). Только звук.

Видеокодеки

AV1 VP9 H.264 H.265

Внутри: av01 · vp9 · avc1/h264 · hvc1/hev1/bytevc1. Нужного кодека нет — берётся ближайший.

Аудиокодеки

OPUS AAC

Фильтрация через acodec^=opus или acodec^=mp4a с запасным вариантом без фильтра.

Разрешение и FPS

144p 720p 1080p 4K+

Список строится из реальных форматов, у вертикальных видео — в виде 1080x1920. Условия height<= и fps<=.

Обрезка секций

ЧЧ:ММ:СС

--download-sections *start-end + --force-keyframes-at-cuts. Скачивается только нужный фрагмент.

Аудиодорожка

Авто RU EN

Список языков берётся из самого видео. Выбранная дорожка пробуется первой, иначе качается обычная.

Субтитры

Нет RU EN (авто)

Обычные и автоматические субтитры оригинала. Вшиваются в MKV или MP4 через --embed-subs.

Размер файла

~604,80 МБ

Итоговый размер считается до начала загрузки по тому же формату, который будет скачан.

Встроенный планировщик

Запланируйте загрузку на конкретное время — программа справится сама, пока вы заняты другими делами.

  • Дата и время — вручную или через встроенный календарь
  • Несколько ссылок в одной задаче, скачиваются по очереди
  • Те же параметры, что и в главном окне: формат, кодеки, дорожка, субтитры, разрешение, FPS, браузер, папка
  • Обратный отсчёт до старта и работа в фоне при закрытом окне
  • После завершения: ничего не делать, выключить, сон или гибернация
  • Звук и уведомление Windows с итогом по ссылкам

Отложенные задачи

Точная нарезка

Обрезка видео на лету

Нажмите ⚙ рядом с полем ссылки и укажите нужный диапазон — загрузится только он.

  • Старт и конец в формате ЧЧ:ММ:СС
  • Только начало — до конца файла: *start-inf
  • Только конец — с начала файла: *0-end
  • Принудительные keyframes на границах нарезки
  • Пустые поля — скачать ролик целиком

Детальный прогресс

Полная картина загрузки в реальном времени — ничего не скрыто.

  • Процент, МБ скачано и всего, скорость и оставшееся время
  • Видно, что качается сейчас: видеопоток, аудиопоток или субтитры
  • «Финальная обработка файла…» при слиянии через FFmpeg
  • Прогресс дублируется в заголовке окна Windows
  • Красно-оранжевая полоса при загрузке, зелёная при успехе, красная при ошибке
  • Звук при завершении и при ошибке

Полная видимость

Ничего не потеряется

История загрузок

Нужно скачать что-то ещё раз или найти старую ссылку — это пара кликов.

  • Окно «Настройки → История загрузок…» с названием и датой каждой записи
  • Поиск по названию и по ссылке
  • «Вставить» подставляет ссылку, «Скачать снова» (или двойной щелчок) запускает загрузку
  • Удаление отдельной записи и очистка всей истории
  • Последние 5 ссылок — в выпадающем списке рядом с полем ссылки

Умная система обновлений

При каждом запуске RedStream проверяет программу, yt-dlp и ffmpeg

Вышла новая версия «3.4». Нажмите сюда, чтобы обновить.✕
yt-dlp устарел (2026.03.17 → 2026.04.01). Нажмите обновить, чтобы продолжить.✕
ffmpeg устарел (2026-09-01 → 2026-10-15). Нажмите обновить, чтобы продолжить.✕

Жёлтая плашка — сама программа: клик скачивает свежий RedStream.exe, подменяет им текущий и перезапускает приложение, ход загрузки виден прямо в плашке. Зелёная — yt-dlp, синяя — ffmpeg: они ведут к Дополнительно → Обновить компоненты.

Плашки выходят поверх панели меню, поэтому размер окна не меняется. Если их несколько, они сменяют друг друга, а крестик справа закрывает любую.

C++17 / MinGW-w64

Для разработчиков. Программа написана на C++17 поверх Win32 API и GDI+.

# Клонировать и перейти git clone https://github.com/frostbittenbull/RedStream.git cd RedStream # Собрать RedStream.exe (нужны x86_64-w64-mingw32-g++ и windres) sh build.sh
Сборка статическая: зависимости (json.hpp) лежат в репозитории.
Для работы нужны рядом: yt-dlp.exe · ffmpeg.exe · 7za.exe — программа скачает их при первом запуске.

Всё под контролем

Настройки, удобство и мониторинг на любой вкус

Папка загрузок

По умолчанию — «Загрузки/RedStream Downloader». Путь меняется плашкой «Папка» и запоминается. В планировщике та же папка.

История ссылок

Окно с поиском и повторным скачиванием. Сами записи лежат в history.txt, который открывается из окна истории.

Автозапуск Windows

Галочка в «Настройках» прописывает программу в автозагрузку Windows. Вступает в силу сразу, без перезапуска.

Уведомление Windows

По завершении появляется системное уведомление с названием видео. Работает даже при свёрнутом окне.

Прокси

HTTP, SOCKS4, SOCKS5 с логином и паролем. Настройки сохраняются и передаются в yt-dlp через --proxy.

Системный трей

Из трея можно открыть окно, обновить компоненты, посмотреть «О программе» или выйти.

Лог-файл

Причины ошибок записываются в log.txt. Открывается из «Настройки → Открыть лог-файл».

Звуковые сигналы

Успех — Windows Background.wav, ошибка — Windows Foreground.wav. Нет файла — системный сигнал.

После завершения

В планировщике можно выбрать: ничего не делать, выключить, сон или гибернация. Перед действием есть время отменить.
